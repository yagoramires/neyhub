# NeyHub

> Em construção.

O NeyHub vai ser a loja e o hub dos meus apps de barra de menus do macOS: instalar, atualizar e usar cada um num lugar só, sem lotar a barra de menus.

Os apps continuam sendo repositórios separados e funcionam sozinhos, fora do NeyHub:

| App | O que faz |
|---|---|
| [Aero](https://github.com/yagoramires/aero) | Encaixe de janelas como no Windows. |
| [Capture](https://github.com/yagoramires/capture) | Print e gravação de tela pela barra de menus. |
| [Hub](https://github.com/yagoramires/hub) | Aparelhos da casa (Tuya, Smart Life, SmartThings) pela barra de menus. |
| [Dose](https://github.com/yagoramires/dose) | Controle de remédios e suplementos. |
| [Pauta](https://github.com/yagoramires/pauta) | Jira, Slack e GitHub numa tela só. |
| [Deck](https://github.com/yagoramires/deck) | Configura o fifine AmpliGame D6 sem o app oficial. |
